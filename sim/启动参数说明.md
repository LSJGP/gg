# `run_sim.py` 启动参数说明

在 `sim` 目录下执行；`run_sim.py` 会 **`bazel run //cpp:sim_runner`** 调用 C++ 闭环仿真。Python 规划与旧版入口见仓库 **`pysim/`**（含 `run_default.sh`）。

也可使用 `python3 run_sim.py --help` 查看 argparse 自带的帮助（与下表一致）。

---

## 必参与场景

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--scenario-dir` | 路径 | （必填） | 场景目录，需包含 `scenario_meta`、`dynamic_objects`、`lane_graph` 等 JSON（由仓库 `tools` 转换流程产出）。若缺少 `scenario_meta` 中的 init/goal，程序会退出并报错。 |

---

## 规划器与路由

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--planner` | 字符串 | `reference_tracker` | C++ 已注册名称：`reference_tracker`、`goal_seek`、`local_dwa` 等（见 `sim_runner` 启动失败时 stderr 列出的列表）。 |
| `--desired-speed` | 浮点 | `13.9` | 期望速度（m/s），供规划器参考。 |
| `--reference-step` | 浮点 | `1.0` | 兼容参数；当前 C++ `sim_runner` 忽略。 |

---

## 仿真步长与时长

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--dt` | 浮点 | `0.1` | 仿真 / 控制时间步（秒）。 |
| `--max-seconds` | 浮点 | `0.0` | 大于 0 时覆盖场景时长，只跑前若干秒；`0` 表示用场景完整时间范围。 |
| `--stop-on-collision` | 标志 | 关 | 出现**第一帧非豁免碰撞**时结束仿真。 |
| `--no-interpolate-npcs` | 标志 | 关 | NPC 在时间上使用最近邻采样；**不设**此标志时默认对 NPC 做线性插值。 |

---

## 自车几何与动力学（自行车模型 + OBB）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--ego-length` | 浮点 | `4.5` | 车长（米）。 |
| `--ego-width` | 浮点 | `1.85` | 车宽（米）。 |
| `--ego-wheelbase` | 浮点 | `2.7` | 轴距（米）；Pure Pursuit 与部分 planner 会用到。 |
| `--ego-rear-overhang` | 浮点 | `0.95` | 后悬（米）。 |
| `--ego-max-speed` | 浮点 | `33.3` | 自车最大速度上限（m/s）；评分器中的限速类指标会参考 SimLog 中的自车状态。 |

---

## 输出与 SimLog

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--output` | 路径 | `<仓库根>/output/log/sim_log.json` | SimLog JSON；父目录会自动创建。 |
| `--source-tag` | 字符串 | `waymo_sim_cpp` | 写入 SimLog 顶层的 `source` 字段。 |

---

## C++ 评分器 `grading_main`

仅在设置了 `--grading-bin` 且 `--cpp-mode` 不是 `off` 时启用。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--grading-bin` | 路径 | 空 | `grading_main` 可执行文件路径；为空则**不**启动 C++ 评分子进程 / 批处理。 |
| `--grading-report` | 路径 | 空 | 为空时使用 **`<仓库根>/output/report/grading_report.json`**（与默认 `--output` 配套）。 |
| `--metrics-config` | 路径 | 空 | 传给 `grading_main` 的 metrics JSON；为空则使用评分器内置默认。 |
| `--log-dir` | 路径 | 空 | 非空时写入带时间戳的 `sim_*.log`（spdlog 文本；见 `sim/cpp/sim_logger`）。 |
| `--log-level` | 枚举 | `info` | 与 `--log-dir` 联用：`trace` / `debug` / `info` / `warn` / `error` / `off`。 |
| `--cpp-mode` | 枚举 | `online` | `online`：仿真过程中通过 `grading_main --stream` 逐帧 stdin 写入；`offline`：仿真结束后执行 `grading_main <SimLog> <report>` 一次批处理；`both`：先在线再离线（最终报告以离线那次覆盖同一路径）；`off`：即使有 `--grading-bin` 也不调用 C++。 |
| `--no-python-grader` | 标志 | — | 兼容旧参数；当前 C++ 路径下无进程内 Python grader，传此标志仅打印提示。 |

---

## 日志与预留

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--print-every` | 整数 | `10` | 兼容参数；当前 C++ `sim_runner` 未使用。 |
| `--seed` | 整数 | `0` | 预留给未来随机性 planner，当前逻辑未使用。 |

---

## 退出码（简要）

- 正常结束：一般为 `0`。
- 场景缺少 init/goal：`2`。
- `--grading-bin` 指向的文件不存在：`3`。
- 离线批处理 `grading_main` 非零退出：透传其返回码。
- 兼容保留：`10`（历史为 Python grader 未通过）。

---

## 示例

仅仿真并写默认 SimLog：

```bash
cd sim
python3 run_sim.py --scenario-dir ../scenarios/waymo_scenario_5
```

指定输出并调用 C++（在线流式），报告与 SimLog 同目录：

```bash
python3 run_sim.py \
  --scenario-dir ../scenarios/waymo_scenario_5 \
  --output /tmp/sim_log.json \
  --grading-bin ../grading_mini/bazel-bin/src/entry/grading_main \
  --grading-report /tmp/grading_report.json
```

只用 C++、不要 Python grader：

```bash
python3 run_sim.py \
  --scenario-dir ../scenarios/waymo_scenario_5 \
  --grading-bin ../grading_mini/bazel-bin/src/entry/grading_main \
  --no-python-grader
```

事后批量评分（不写在线管道）：

```bash
python3 run_sim.py \
  --scenario-dir ../scenarios/waymo_scenario_5 \
  --grading-bin ../grading_mini/bazel-bin/src/entry/grading_main \
  --cpp-mode offline
```
